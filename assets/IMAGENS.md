# Fotografias do portfólio

O `index.html` utiliza fotografias ilustrativas remotas do Unsplash. Os links estão no código JavaScript, nas constantes `PJ` e `PROJECT_DETAILS`.

As fotografias são carregadas online e não foram copiadas para este pacote. Para tornar o site totalmente autónomo/offline, descarrega imagens que tenhas direito a utilizar, guarda-as nesta pasta e substitui no HTML cada URL `https://images.unsplash.com/...` pelo caminho local correspondente, por exemplo `assets/nome-da-fotografia.jpg`.
