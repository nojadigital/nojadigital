# Noja Digital — Website

Website estático da Noja Digital, pronto para publicação no GitHub Pages ou Vercel.

## Estrutura

- `index.html` — página principal e funcionalidades do website.
- `assets/` — fotografias locais utilizadas no portfólio.
- `README.md` — estas instruções.

## Fotografias

As imagens do portfólio estão guardadas localmente em `assets/`. Não dependem de links externos para abrir. As fotografias representam personagens e profissionais negros, alinhados com a identidade e o público da Noja Digital.

## Publicar no GitHub Pages

1. Cria um repositório no GitHub.
2. Envia `index.html`, `README.md` e a pasta `assets/` para a raiz do repositório.
3. Abre **Settings → Pages**.
4. Em **Build and deployment**, escolhe **Deploy from a branch**.
5. Seleciona a branch `main` e a pasta `/ (root)`, depois guarda.

## Publicar na Vercel

1. Importa o repositório GitHub na Vercel.
2. Mantém as configurações padrão para um site estático.
3. Clica em **Deploy**.

## Nota

O site utiliza HTML, CSS e JavaScript no próprio `index.html`. Não é necessário instalar dependências nem executar um processo de build.
